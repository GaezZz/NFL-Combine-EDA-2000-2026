# NFL Combine EDA (2000–2026)
Exploratory Data Analysis of NFL Combine data from 2000 to 2026, focused on investigating the relationship between athletes' physical attributes, athletic performance, and their likelihood of being selected in the NFL Draft.

Using Drafted as the target variable, this project explores whether Combine measurements and performance metrics can help distinguish between drafted and undrafted prospects.

The analysis focuses on:

* Comparing physical attributes and athletic performance between drafted and undrafted players.
* Identifying which Combine metrics show the strongest relationship with Draft selection.
* Exploring differences in athletic profiles across playing positions.
* Investigating correlations, distributions, and potential outliers.
